# Como usar

Baixe o [ZIP do ksiezyclive para Windows x64](https://github.com/PedroAyan/ksiezxclive/releases/latest/download/ksiezyclive-windows-x64.zip), extraia os arquivos e abra `ksiezyclive.exe`.

**Para gravar**, abra a aba **Gravar**, escolha o monitor e a fonte de áudio e clique em **Iniciar gravação**. Quando terminar, clique em **Parar gravação**. O app mostra onde salvou o MP4.

**Para transmitir**, abra a aba **Live** e escolha **Tela inteira** ou **Janela de aplicativo**. Selecione o que quer mostrar e o áudio que a pessoa vai ouvir. Se a janela estiver minimizada, restaure antes de começar. Clique em **Abrir live** e, quando aparecer **Ao vivo**, use **Copiar link**. Na primeira vez, siga o [guia de configuração do servidor](docs/configuracao.md).

**Para assistir**, abra o link recebido no navegador e clique em **Assistir**.
